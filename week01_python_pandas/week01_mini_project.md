# Week 1 Mini Project: Simple Sales Analysis

## Scenario

คุณได้รับข้อมูลยอดขายตัวอย่างจากร้านค้าขนาดเล็ก ผู้จัดการอยากรู้ว่ายอดขายมาจาก region ไหน สินค้าหมวดไหนขายดี และควรสนใจอะไรต่อในเดือนถัดไป

ใช้ไฟล์:

`../data/simple_sales.csv`

## Business Questions

ตอบคำถามเหล่านี้ด้วย pandas:

1. Region ไหนมียอดขายสุทธิสูงที่สุด?
2. Region ไหนมียอดขายสุทธิต่ำที่สุด?
3. Category ไหนสร้างยอดขายสุทธิสูงที่สุด?
4. Product ไหนขายได้จำนวนชิ้นรวมสูงที่สุด?
5. Product ไหนสร้างยอดขายสุทธิสูงที่สุด?
6. ลูกค้า New หรือ Returning สร้างยอดขายสุทธิมากกว่า?
7. Order ไหนมีส่วนลดเป็นจำนวนเงินมากที่สุด?
8. Region + Category คู่ไหนสร้างยอดขายสุทธิสูงที่สุด?
9. ยอดขายสุทธิเฉลี่ยต่อ order เท่าไร?
10. ถ้าต้องเลือก 1 category เพื่อทำ promotion ต่อ ควรเลือกอะไร และเพราะอะไร?

## Required Columns

ก่อนตอบคำถาม ให้สร้าง columns:

- `gross_sales`
- `discount_amount`
- `net_sales`

## Expected Output

ใน notebook ควรมี:

1. โหลดข้อมูล
2. สำรวจข้อมูลเบื้องต้น
3. สร้าง calculated columns
4. วิเคราะห์ด้วย filter, sort, groupby
5. สรุป insight อย่างน้อย 5 ข้อ
6. recommendation สั้น ๆ 1 ย่อหน้า

## Insight Template

เขียน insight ในรูปแบบนี้:

```text
Insight 1:
จากข้อมูลพบว่า ... มีค่า ... ซึ่งแปลว่า ...

Insight 2:
จากข้อมูลพบว่า ... เมื่อเทียบกับ ... จึงน่าสนใจว่า ...
```

## Recommendation Template

```text
จากการวิเคราะห์เบื้องต้น ร้านควรให้ความสำคัญกับ ... เพราะ ...
อย่างไรก็ตาม ข้อมูลนี้ยังมีข้อจำกัดคือ ... ดังนั้นก่อนตัดสินใจจริงควร ...
```
