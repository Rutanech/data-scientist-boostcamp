# Week 1: Python for Data Science

เป้าหมายของสัปดาห์นี้คือใช้ Python และ pandas เพื่ออ่านข้อมูล สำรวจข้อมูล เลือกข้อมูล กรองข้อมูล จัดกลุ่ม และสรุป insight เบื้องต้น

## ไฟล์ที่ใช้

- `../data/simple_sales.csv` ชุดข้อมูลยอดขายตัวอย่าง
- `week01_python_pandas.ipynb` โน้ตบุ๊กฝึก Python และ pandas
- `week01_study_plan.md` แผนเรียนรายวัน
- `week01_exercises.md` แบบฝึกหัดเพิ่มเติม
- `week01_mini_project.md` โจทย์ mini project
- `week01_checklist.md` checklist ก่อนขึ้น Week 2
- `learning_log.md` บันทึกสิ่งที่เรียนและ insight

## แผนเรียน 5 วัน

| วัน | งานหลัก |
|---|---|
| Day 1 | Python basics และเปิดอ่าน CSV |
| Day 2 | เลือก columns, filter rows, sort values |
| Day 3 | สร้าง column ใหม่และคำนวณยอดขาย |
| Day 4 | ใช้ groupby เพื่อตอบคำถามจากข้อมูล |
| Day 5 | ทำ mini project และสรุป insight 5 ข้อ |

## ผลลัพธ์ที่ต้องมี

- Notebook ที่รันได้ครบ
- Insight อย่างน้อย 5 ข้อใน `learning_log.md`
- เข้าใจคำสั่งหลัก: `read_csv`, `head`, `info`, `describe`, `loc`, `sort_values`, `groupby`
- ตอบคำถามจากข้อมูลได้ด้วย pandas โดยไม่ดูเฉลยทุกบรรทัด
- อธิบายผลลัพธ์เป็นภาษาคนอ่านรู้เรื่อง ไม่ใช่แค่โชว์ตาราง
